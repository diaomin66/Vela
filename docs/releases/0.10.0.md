# AhaX 0.10.0

本版集中改善界面可读性和一致性，让日常信息更容易找到、比较和操作。

- 六个工作区采用固定侧栏，正文独立滚动；窄窗口切换为完整的顶部导航。
- 主信息采用 14px、辅助信息 12–13px，提高浅色和深色下的文字对比度；减少淡色小字和重复嵌套面板。
- 模型库对齐模型、推理强度、默认状态与操作；渠道直接展示密钥状态和当前默认渠道。
- 线程概览压缩为保护状态、数量和数据来源，列表与列名对齐；单条、批量删除、找回及回收站统一视觉层次。
- 评测结果使用有列名的连续列表，作品展示真实模型 ID、档位、状态与耗时，定时评测明确展示 24 小时通过率。
- 表单、下拉、抽屉和弹窗统一圆角、间距、输入边界、键盘焦点及选中状态，保存操作固定在底部。
- 数据位置按官方数据、AhaX 数据和线程保护分组，保留变更预览和重启迁移流程。

0.9 的自定义路径、持久化保护和可逆线程删除继续保留。可逆删除仍限于已经验证的会话格式；无法确认完整副本或线程关联时会说明原因并阻止该项操作。
