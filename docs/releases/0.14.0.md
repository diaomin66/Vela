# ahaX Beta 1 · 0.14.0

首个对外测试版统一 ahaX 品牌，并完善旧版本迁移与模型路由边界。安装后从桌面打开，已有用户可使用软件内置更新。

- 产品名称统一为 ahaX，更新应用、托盘、任务栏和快捷方式图标。程序文件、应用标识、默认服务商和新导出内容使用新品牌。
- 仓库与更新入口统一为 `diaomin66/ahaX`，旧地址保留跳转，更新公钥继续沿用。
- 默认数据迁入 ahaX 目录，校验复制结果后启用；保留旧源并兼容历史凭据、加密快照与用户自定义位置。遇到冲突或无法安全迁移时明确说明原因。
- 新模型目录使用 `ahax-` 路由，兼容已保存的旧路由、默认选择与请求。渠道模型仍使用服务商的真实模型 ID。
- 增加内部路由误填拦截和服务商错配诊断，避免将内部模型编号发送给第三方。界面新增旧会话 404 处理帮助。
- 保持雾蓝配色与浅深主题，统一标志和文字，迁移已有主题偏好。继续使用共享控件与已有页面结构。

**旧会话说明：** 已有直连会话可能继续绑定原服务商。继续该会话时，选择原服务商支持的真实模型名；使用统一模型库时，重新同步配置、重开客户端并新建会话。切换模型不会自动迁移旧会话的服务商，更名不会改写历史消息。

Windows x64 安装包：`ahaX_0.14.0_x64-setup.exe`。已有用户在「设置 → 软件更新」检查更新。手动安装前，从系统托盘完全退出旧版。具体完成的验收项目见本仓库 `docs/validation/0.14.0.md`。
