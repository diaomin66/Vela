# Vela 0.5.1

- 模型评测支持自定义单次请求超时：新计划默认 5 分钟，支持 2、5、10、30 分钟预设以及 30–3600 秒自定义。
- 每题与独立评审分别计时，手动、定时和导出保留当轮设置；旧计划与历史继续按原 120 秒解释。
- 超时信息显示实际设置，并区分网络中断；超时不计零分、不自动重试，随时可停止。
- 超时失败保留真实等待时长；重启恢复保留已完成结果，避免误标为中断。
- 诊断模型路由与服务商错配，修复旧版直连残留 Vela 目录和当前 profile 目录覆盖的问题。
- 接入说明明确提醒重新打开客户端并新建对话。已有对话只切换模型不会自动更换服务商。

`vela-…` 是多渠道内部路由 ID，正常由本机后台转换为服务商的真实模型名；遇到第三方「无可用渠道」时请检查是否在旧直连对话中选用了 Vela 模型。

通过「设置 → 软件更新」下载并安装，或下载 Windows x64 安装包。更新包启用签名验证，安装器尚未配置 Authenticode 代码签名。
