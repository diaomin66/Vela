# AhaX 0.12.0

本版重建界面的阅读层级与共享样式，让渠道、模型、评测、线程、诊断和恢复使用一致的文字、控件与布局。

- 优先使用 Windows 可读字体，采用 28 / 20 / 18 / 16 / 14 / 13px 层级，分别区分页面标题、分组、对象名称、正文与输入、操作与标签、辅助元数据。
- 字重、行高、间距、圆角与主题颜色使用语义令牌；主要控件统一为 44px，紧凑行内操作为 36px。
- 六个工作区共享页面标题、分组标题和工具栏结构。评测子页面、线程筛选、设置和结果页签使用一致的分段选择，选中项更明确。
- 浅色与深色采用中性配色，主要文字按至少 7:1、辅助文字与操作文字按至少 4.5:1 的对比度标准设计；状态同时以文字表达。
- 渠道名称、模型名称与线程标题优先呈现，地址、时间、路径和数量使用辅助层级。搜索、筛选与结果靠近，信息排列更紧凑，减少重复框线与说明。
- 设置、模型编辑、评测计划和选择列表统一字段标签、输入边界、焦点与选中状态。抽屉头尾固定，保存操作持续可达，高级字段按需展开。
- 评测作品、答案、记录与定时概况使用相同信息层次，保留动画展示、详情、历史与删除入口。
- 窄窗口通过换行、纵向布局和操作区重排适配，不缩小正文或字段字号。主导航与底栏保持常驻，内容区独立滚动。

安装包为 `AhaX_0.12.0_x64-setup.exe`。已有版本可在「设置 → 软件更新」检查更新。

本版沿用已有渠道、凭据、评测记录、线程保护与回收数据。应用保留「设置 → 数据位置」中的自定义配置，包括官方数据与索引、配置备份、评测与导出、线程保护和线程索引目录，无需因界面升级重新选择位置。原有模型接入、诊断修复、配置恢复与更新流程继续保留。
