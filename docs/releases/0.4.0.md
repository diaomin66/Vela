# Vela 0.4.0

- 新增内置软件更新：后台检查 GitHub Release，自动下载并验证签名，在任务结束后手动安装。
- 设置中可查看当前版本、更新内容与下载进度，也可关闭自动下载或手动检查。
- 更新包绑定发行版本并校验签名，下载或验证失败不会启动安装。
- 依据官网重新整理逐型号推理能力，支持 GPT‑5.6、GPT‑6、GPT‑6.1 系列及 `max`，修正 `none`、Pro 型号的可用档位与默认值。
- 模型列表按渠道分组，支持原生推理强度与默认值配置。
- 渠道与设置采用圆角抽屉，导航常驻，高级配置按需展开。
- 保留已有渠道资料、系统凭据与配置备份。

Windows x64。首次安装或从 0.3 及更早版本升级，请从托盘退出旧版后运行安装包；0.4 起可在软件内获取后续更新。

含 `max` 的模型目录需要新版官方客户端（CLI 0.138 或以上，建议保持当前版本）。服务商自定义别名可手动指定档位；不把 `ultra` 当作 API 参数透传。

更新签名已启用，Windows 安装包暂未配置 Authenticode 代码签名。
