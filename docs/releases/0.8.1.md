# AhaX 0.8.1

新增独立的本地线程保护与找回系统，并完善 Windows 路径兼容。

- 自动识别当前数据目录中的活动、归档、压缩与历史版本记录。
- 线程管理页支持搜索、来源筛选、分页、详情及原生打开。
- 默认每 60 秒增量保护，可自定义间隔；配置变更前可创建保护检查点。
- 使用当前 Windows 用户加密的分块快照，保留完整性校验和独立清单，重启后可补偿未提交记录。
- 支持单条与批量预览找回；目标有不同内容时拒绝覆盖。
- 支持官方列表重新索引，以及 AhaX 自身清单从快照重建，不直接改写官方数据库结构。
- 支持大日志、长路径，区分来源离线、目录扫描不完整和写入中记录。
- 识别历史基础依赖；缺失、截短或循环时明确提示，恢复前重新校验所需历史。
- 修正 Windows 短路径与长路径指向同一文件时的索引匹配，缺失路径仍保留可比较的原信息。

保护副本保存在本机。首次保护前已永久删除且没有其它副本的内容无法凭索引还原；DPAPI 副本通常仅能由创建它的 Windows 用户解密。
