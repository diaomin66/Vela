# AhaX 0.9.0

新增自定义数据位置与线程回收站。

- 在设置中分别选择官方配置与索引目录、配置备份、评测数据、导出文件、线程保护与线程索引目录，支持 Windows 文件夹选择器。
- 保存位置前预览变更，重启时校验并复制 AhaX 数据。旧数据保留，目标中的不同内容不会被覆盖，渠道凭据与网关身份保持稳定。
- 线程支持单条与批量删除、删除预览、逐项结果，以及从回收站撤销。
- 删除标记独立持久化，扫描和重建保护清单时尊重用户的删除操作。
- 删除前核对保护状态与关联历史，通过本机官方线程服务执行；不能安全处理的记录显示具体原因。

当前可逆删除已验证传统会话格式；分页历史暂不开放删除，以避免在只读索引刷新无法重建历史投影时出现不完整撤销。

数据位置的生效方式与环境变量优先级见 `docs/LOCATIONS.md`；线程保护与恢复边界见 `docs/THREADS.md`。
