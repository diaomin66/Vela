# AhaX 0.11.1

这一版重新设计整个桌面工作区，让渠道、模型、评测与线程管理更轻、更集中。

- 采用中性浅色与石墨深色，主要操作使用黑白按钮，状态色仅用于表达当前状态。
- 标题栏、侧栏和底部状态融入窗口背景，正文在独立圆角工作区滚动；导航始终可达。
- 渠道改为横向卡片，名称、默认状态、余额、已启用模型和管理入口有清晰层次。新增按渠道名称、API 地址、模型名称或备注搜索。
- 模型库统一列标题，渠道使用轻量分组，推理强度、默认状态和模型操作保持对齐。
- 顶栏可一键切换浅色、深色、跟随系统；偏好自动保存，与设置中的外观选择同步。
- 线程筛选与搜索集中到一条工作栏；保护概览、连续记录和状态标签减少重复边框。
- 评测子导航、测试类型、作品画布、答案列表与历史记录统一样式，保留动画自动播放及删除操作。
- 设置与编辑使用浮动圆角抽屉、填充式输入和轻量下拉，外观选择提供窗口预览，保存区保持固定。
- 诊断结果和配置恢复减少嵌套容器，保留问题说明、修复预览和备份流程。

安装包为 `AhaX_0.11.1_x64-setup.exe`。已有版本可在设置中检查更新。升级沿用原有渠道、数据位置和更新签名公钥。
