# AhaX 0.13.0

本版重新组织工作区布局，并将主操作与选择反馈统一为雾蓝色。页面采用开放画布，减少包围整页和重复信息的容器。

- 浅色强调色为 `#4165a0`，深色为 `#9fbdec`；普通内容保持中性表面，状态颜色只用于相应提示。
- 界面采用随程序打包的 Manrope 与 Noto Sans SC。对象名称使用 500 字重，页面与章节标题使用 600 字重，保留 28 / 20 / 18 / 16 / 14 / 13px 阅读层级。
- 渠道在宽工作区中双列排列，名称、模型数量、余额与操作分别对齐。窗口变窄时转为单列。
- 模型库改为连续列表，每行标明来源渠道，并保留显示备注与原始模型 ID 的对应关系。搜索、渠道筛选、推理强度、默认模型与验证入口集中在同一列表中。
- 线程页合并范围切换、搜索、来源筛选与管理工具，保留连续记录、分页和单条或批量操作。
- 评测在宽工作区采用项目侧栏，项目选择与结果并排呈现；窄工作区切换为横向项目选择，键盘导航方向同步适配。单次检测与定时评测继续分别管理。
- 设置拆成「常规」「数据位置」「软件更新」三个子页，底栏更新提示直接打开软件更新页。表单与模型选择使用轻边线和柔和填充，抽屉底部操作固定。
- 主要控件保持 44px，紧凑行内操作保持 36px。主要文字按至少 7:1、辅助文字与操作文字按至少 4.5:1 的对比度标准设计；窄窗口通过换行与重排适配，主导航与底栏保持常驻。

安装包为 `AhaX_0.13.0_x64-setup.exe`，下载入口为 [0.13.0 发布页](https://github.com/diaomin66/Vela/releases/tag/v0.13.0)。已有版本可在「设置 → 软件更新」检查更新；手动安装前，从系统托盘完全退出旧版。

本版沿用已有渠道、凭据、评测记录、线程保护与回收数据。「设置 → 数据位置」中的官方数据与索引、配置备份、评测与导出、线程保护和线程索引目录继续保留，无需因界面调整重新选择。模型接入、诊断修复、配置恢复与签名更新流程继续沿用。
