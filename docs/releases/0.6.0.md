# Vela 0.6.0

- 评测界面重做：鹈鹕动画作品库、糖果与判题的 24 小时检测时间线，统一圆角、渠道筛选和可回溯报告。
- 鹈鹕使用完整的 HTML/SVG 2D 动画提示词，保留 CSS、SVG 与脚本动画，取消静态结构分与自动复评。
- 动画按需加载，支持暂停、播放和重播；每个半小时时段区分通过、答错、请求失败、取消与未检测。
- 使用 TanStack Query 管理数据缓存和刷新，Radix 管理标签页、提示和弹层；报告、作品、时间线和调度独立维护。
- 新计划支持 30 分钟间隔，保留旧计划的时间设置、自定义请求超时、手动评测及后台定时。
- 自动建立紧凑历史索引，兼容旧 SVG 和评测报告；保留 100 轮记录与用户主动导出的文件。

生成作品在独立预览环境中运行。内嵌动画与脚本可播放，外部网络资源及本机应用访问被隔离；原始 HTML 保持完整。

在「设置 → 软件更新」下载并安装，或使用 Windows x64 安装包。更新包启用签名与版本验证。
