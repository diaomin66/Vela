# AhaX 0.9.1

新增自定义数据位置与线程回收站。

- 在「设置 → 数据位置」分别选择官方配置与索引目录、配置备份、评测数据、导出文件、线程保护与线程索引目录，支持 Windows 文件夹选择器。
- 保存位置前预览变更，重启时校验并复制 AhaX 数据，支持 Windows 长路径。旧数据保留，目标中的不同内容不会被覆盖，渠道凭据与网关身份保持稳定。
- 线程支持单条与批量删除、删除预览、逐项结果，以及从回收站撤销。
- 删除标记独立持久化，扫描和重建保护清单时尊重用户的删除操作。历史来源记住各自的索引数据库位置。
- 删除中断可进入回收站检查；恢复文件成功后，官方列表尚未刷新的原因会持续显示。

当前可逆删除已验证传统会话格式；分页历史暂不开放删除，以避免在只读索引刷新无法重建历史投影时出现不完整撤销。无法确认完整副本或线程关联时会显示原因并停止该项。

官方目录只切换 AhaX 访问位置，不自动搬迁官方会话与数据库。数据位置的生效方式与环境变量优先级见 `docs/LOCATIONS.md`，线程保护与恢复边界见 `docs/THREADS.md`。
