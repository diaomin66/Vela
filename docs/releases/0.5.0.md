# Vela 0.5.0

- 新增「评测」工作区：手动或定时测试最多 6 个渠道模型，保存原始回答、耗时、用量与题库版本。
- 内置糖果策略、鹈鹕骑自行车 SVG、六题判题能力测试，提供本机参考答案检查和可选模型复评。
- 支持安全绘图预览、停止后续请求、历史对比、JSON 导出；定时默认关闭，可在主页面暂停。
- 补齐官方原生 Ultra：对明确支持的型号提供 Ultra 选择、多代理 v2 元数据和对应实际推理强度，支持历史配置恢复。
- 保持 `max`「最高」和 `Ultra` 独立。直接 API 评测只使用普通推理档位，避免发送无效的 `ultra` 参数。
- 改善 Windows 短暂文件占用时的保存行为，保留错误码与必要暂存文件；导出报告后显示保存位置。

现有 0.4 用户可在「设置 → 软件更新」下载并安装。本轮评测请求会按所选渠道计费，界面在开始前展示每轮调用上限；未启用定时不会后台调用模型。

鹈鹕结构分不评价画面质量，模型复评属于主观意见；单组题目不作为 IQ 或模型身份认证。Ultra 已使用官方 CLI 0.160.0 验证，更新统一目录后重新打开 Codex 并新建任务。

Windows x64。启用更新包签名，安装器尚未配置 Authenticode 代码签名。
