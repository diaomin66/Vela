# AhaX 0.7.0

- Vela 正式更名为 AhaX，窗口、托盘、安装包和新导出文件使用新名称；仓库、更新源、既有数据目录、凭据与模型路由保留兼容标识。
- 评测分成「单次检测」与「定时评测」两个子页面，分别配置本轮检测与后台计划，并按来源展示各自记录。
- 单次糖果与判题按回答逐条展示；定时评测保留 24 小时、48 格时间线与每个时段的具体记录。
- 历史支持删除一轮、勾选和全选批量删除；确认后同步移除该轮全部模型结果、作品和摘要。运行中记录不能删除，已导出的 JSON 保留，定时计划不受影响。
- 鹈鹕作品自动播放，移除暂停按钮，详情保留重新播放、题目和完整原文。继续支持旧 SVG、独立动画预览与按需加载。
- 改用简洁的中性配色，提供浅色、深色、跟随系统三种外观，选择即时生效并记住设置；圆角面板、弹层与固定主导航保持统一。
- 诊断优先显示待处理问题，已通过项目可折叠；补充配置字段、只读状态、受管模型目录和恢复点预检，支持导出脱敏报告，修复完成后自动重新检查。
- 后端将删除事务与恢复独立维护，前端继续复用 TanStack Query 和 Radix。保留自定义超时、旧计划间隔、历史比较、原题库与最多 100 轮记录。
- 修复运行评测时重复启动应用可能误标中断的问题；改进 Windows 暂时阻止结果文件替换时的本地持久化处理，不重发模型请求。

Windows x64 安装包名称为 `AhaX_0.7.0_x64-setup.exe`。原 Vela 0.4 及后续版本继续通过「设置 → 软件更新」读取同一更新源；安装器包含旧安装路径与快捷方式的兼容迁移处理。更新包使用原有签名和版本验证。

诊断默认不调用模型 API；模型评测按所选渠道计费。已生成 HTML 的运行隔离不改写原始回答，外部网络资源仍不会在应用内预览时加载。

具体功能见 [模型评测](../EVALUATIONS.md) 与 [本地诊断与修复](../DIAGNOSTICS.md)，测试和安装升级的实际完成范围见 [0.7.0 验收记录](../validation/0.7.0.md)。
