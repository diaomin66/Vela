## 评测规则与持久化

糖果题明确取出后可观察口味并自适应选择下一次形状，严格核对 JSON 整数 21；使用独立的最坏情况策略搜索验证参考答案。判题任务验证六个完整布尔标签，拒绝重复键、缺项和字符串。鹈鹕任务只评分静态 SVG 技术结构；脚本、事件、外链、HTML、动画和 DTD 不进入图片预览。可选模型复评独立展示，SVG 复评仅看源代码。

Rust 验证覆盖大小与超时边界、重定向和鉴权错误、错误脱敏、无效 API 档位、取消请求、历史恢复、定时抢占、暂停与启动的竞态、题库评分和导出。手动与定时共用单个运行名额，收费请求不自动重试。

内部历史超过 100 轮时仅删除过期的运行记录，用户主动导出的报告独立保留。桌面导出后显示完整保存路径；浏览器演示使用普通 JSON 下载。

`scripts/evaluation-native-smoke.mjs` 直接运行签名安装包内的程序，确认计划和历史落盘、题目与回答完整、分数及 Token 用量可读、JSON 导出真实存在；取消会断开在途本地请求且不再发送评审或后续题目。使用关闭后的隔离计划文件设置已到期时间，再以 `--background` 启动，验证定时只运行一次、下次时间推进、再次重启不重复执行，最后关闭定时。隔离数据不含合成 Key，系统凭据清理完成，接入配置逐字节保持一致。

最终本机安装包另验证了原生评测页面的三条结果与历史、SVG 图片真实解码、题目/原文逐字一致，以及点击导出后的成功提示、绝对路径和文件重写。界面截图使用本机模拟答案，不代表真实模型评测结果。

首次原生评测验证在重启后保存暂停计划时遇到一次 Windows 原子替换失败；同一脚本未增加重试，复跑完整通过，未能追溯该次占用来源。文件层现保留 Win32 错误码，仅对共享/锁冲突进行最多 250 毫秒的局部替换重试，不重复业务或模型请求；遇到部分完成错误保留暂存文件。新增四项 Windows 测试验证短暂占用恢复、持续占用保留原字节、普通读取句柄兼容、重试边界。持续占用或权限错误仍会明确报错。

## 原生 Ultra

从官方目录按精确模型 ID 读取 `multi_agent_version` 与 Ultra 底层 effort。官方 CLI 测试确认 Astra 与 6.1 Sol 的 Ultra 请求使用 `xhigh`，5.6 Sol 使用 `max`，同时出现主动多代理指令与 v2 工具。普通 `max` 仍是独立档位；未证实支持的模型不会自动获得 Ultra。

评测模块直接调用 Responses API，只提供已配置的普通 API 档位；后端拒绝字面 `ultra`，不会将原生多代理模式伪装成单次模型评测。「API 默认」表示不发送 effort，与 Vela 模型目录的默认强度分别处理。

## 发布检查

发布工作流根据版本标签，在 Windows MSVC 环境再次执行类型检查和单元测试，构建带更新签名的安装包，生成版本绑定清单、签名与 SHA-256 文件。公开发行包以 GitHub Release 的 `SHA256SUMS-0.5.0.txt` 为准；本机 GNU 构建与 MSVC 构建不保证字节一致。

## 验证边界

本机模拟服务可验证程序协议与状态，不能替代真实第三方服务的模型质量、计费与复杂工具任务验证。评测不提供标准化 IQ 或模型身份认证。未在干净 Windows 虚拟机覆盖首次安装和真实覆盖升级；当前提供更新包签名，尚未配置 Windows Authenticode 代码签名。
