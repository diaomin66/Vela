## 迁移与恢复边界

- 新目录启用前先复制验证，保留旧来源；SQLite 使用一致性备份与完整性检查，普通文件进行哈希和目录集合检查。
- 沿用旧网关凭据身份，兼容新旧加密封套和凭据命名空间；显式删除同时清理新旧凭据。
- 凭据助手升级先于后台调度。精确验证所属安装目录、协议、端点和凭据参数，保留模型选择、推理强度及未应用设置；非当前的受管服务商同样可重绑。
- 内部路由新旧编号指向同一渠道和真实模型，未知编号本地拒绝；不把内部编号作为上游模型发送。
- 旧直连会话仍保留原服务商。它绕过本机网关时，需选择该服务商的真实模型，或重新同步后新建会话。更名不会重写官方会话文件或数据库。
- 历史加密备份可读取；若配置备份仍引用已失效的旧助手路径，恢复会明确拒绝并提示重新应用连接，避免恢复成功后继续调用不存在的程序。
