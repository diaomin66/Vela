# AhaX 0.8.1 验收记录

本版在 [0.8.0 本地完整验收](0.8.0.md) 的线程保护系统上修正 Windows 索引路径兼容。测试继续使用隔离目录与合成线程，没有对真实历史执行恢复或重新索引。

## 发布前发现与修正

0.8.0 的本地 GNU 构建通过 Rust 220 项、前端 45 项、Playwright 47 项，官方互操作与实际桌面持久化流程通过。GitHub Windows MSVC 编译成功后，Rust 测试出现 219 项通过、1 项失败、1 项按设计忽略。失败断言是索引中的当前 rollout 与已扫描文件匹配数量为零。

匹配逻辑原先只统一大小写、路径分隔符和长路径前缀，不能识别同一文件的 Windows 8.3 短路径别名。现对存在的路径先解析真实文件路径，再进行比较；文件已经缺失时保留原来的词法比较，不丢弃索引证据。

新增回归使用 Windows `GetShortPathNameW` 创建真实 8.3 路径输入，修复前在本机复现相同的零匹配，修复后通过，并核对 SQLite 字节未改变。扫描组 27 / 27 项通过，包含缺失路径与 `.zst` 等价路径比较。版本清单一致性检查通过。

0.8.0 流程在发布前停止，没有公开 Release 或更新安装包。保留已有 Git 标签，修正版本使用 0.8.1。

## 验证边界

本机保护、Windows 用户加密、后台运行时间及首次保护前数据丢失的边界与 [线程使用说明](../THREADS.md) 一致。没有运行真实安装器，也没有在真实客户端打开用户线程。
