# AhaX 0.12.0 验收记录

本版重建共享视觉规范，重点解决对象名称、正文、表单与辅助信息的阅读层级不清，以及工作区、抽屉和分段控件样式不一致的问题。

## 前端与界面

- 完整 TypeScript 检查通过，包含产品代码、单元测试及浏览器测试。
- Vitest 55 项通过。新增检查覆盖全局字号与控件尺寸规范，并约束所有应用 CSS 使用语义字号、字重、行高令牌。
- 最终完整 Playwright 61 项通过，输出位于 `artifacts/test-full-v12/`。覆盖渠道、模型、推理选择、评测、线程、数据位置、诊断、主题、键盘焦点和更新流程。
- 可读性检查覆盖六个工作区、浅深主题及 1180 / 900 / 390 三种宽度。主要标题、对象名和可编辑输入按 7:1、辅助信息按 4.5:1 检查实际背景对比度；正文最小 16px、辅助文字最小 13px。
- 设置与模型编辑抽屉检查标签、字段、展开内容、44px 控件和固定操作区。评测计划复用同一 Drawer 与表单页脚，保留提交、取消、浮层键盘与关闭后焦点行为。

实际查看渠道、模型库、线程、评测作品、回答、定时计划、设置及模型编辑的浅深截图。复核中修正了评测首屏结果过晚出现、计划抽屉尺寸不一致、900px 线程概况过早换行和窄屏推理选项缺少可见标签的问题。作品截图等待布局稳定后确认缩放完整，未更改生成内容的隔离机制。

截图位于 `artifacts/screenshots/readability-v12/`、`artifacts/screenshots/readable-data-refinement/` 与 `artifacts/screenshots/readable-forms/`。README 使用本版最终渠道和模型库截图。
