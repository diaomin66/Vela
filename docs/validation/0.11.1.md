# AhaX 0.11.1 验收记录

0.11.1 包含 0.11 系列的整套界面重设计、渠道搜索和快捷主题切换，并修正发布检查发现的测试夹具类型声明。0.11.0 标签保留，未产生公开 Release；应用功能与界面代码保持相同，仅版本标识和测试类型声明更新。

## 发布前检查

修正后的 TypeScript 和 Vitest 53 项通过。此前最终全套 Playwright 59 项、预览隔离文件 24 次重复验证、14 个原生界面状态、9 组线程与存储验证及 31 项隔离安装迁移检查均通过，详细材料见 [0.11.0 验收记录](0.11.0.md)。测试类型声明修正不改变浏览器运行时行为。

类型修正后，预览隔离 4 项再次通过。长渠道名、长 API 地址、长模型备注与大额余额在浅深主题的 1180/900/390 六组布局均无横向溢出或页面错误。新控制边界色对六类背景的最低对比度为浅色 3.084:1、深色 3.590:1。材料：`artifacts/v111-fixture-typecheck.log`、`artifacts/screenshots/v11-edge/edge-report.json`。
