## 原生运行与发布

本机安装包的配置与网关回归通过，包含元数据发现、原始余额单位、根地址与 `/v1` 归一化、双渠道模型改写、推理档位透传、服务商错配诊断与修复、凭据命令、JSON/SSE、鉴权拒绝、续传隔离、托盘与单实例唤回、配置冲突及精确恢复。

首次并发运行时，模拟渠道在保存凭据后出现一次读取失败；停止其他评测实例后使用相同安装包独立重跑通过。失败原因没有得到确定，不据此增加模型请求重试或修改凭据实现。测试没有输出 Key，合成凭据清理正常。

最终本机安装包的原生动画检查通过。实际 WebView2 能执行 JavaScript 与 SMIL，暂停和恢复均生效；主窗口 CSP 限定到当前进程的精确预览端口及随机路径，子帧的外部请求、另一本机端口的 `location` / `meta-refresh` / 顶层导航没有到达目标服务，释放后的作品返回 404。正式构建的内嵌字体正常加载。

原生权限检查没有将“Promise 无响应”当作明确的 ACL 拒绝：子帧的 HTTP IPC 被 CSP 阻断；进一步尝试注入的 fallback 和直接原始 IPC 后，没有成功回调，且后台仍有完整的 127 个剩余预览名额，确认没有额外创建作品的副作用。此结论针对本次安装包、锁定的 Tauri/Wry 依赖和实际 WebView2。
