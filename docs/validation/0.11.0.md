# AhaX 0.11.0 验收记录

本版重做窗口、渠道、模型、评测、线程和共享表单的视觉层次，增加渠道搜索与顶栏外观切换。后台协议、线程保护与存储流程未改动。测试仅使用浏览器演示数据和独立临时目录。

## 前端与视觉

- TypeScript、生产前端构建和 Vitest 53 项通过。
- 最终完整 Playwright **59 项通过，0 失败**，耗时约 1.4 分钟。包括新渠道搜索、顶栏与设置双向外观同步、推理选择、长模型列表、评测、线程删除恢复、数据位置和更新。
- 1180×820、900×680、390px 三种宽度、浅深两种主题的六个工作区均完成截图。正文最低 12px，无主区域横向溢出；导航与底部状态保持可达。
- 已人工查看渠道浅深色、深色模型库、线程、评测作品、诊断和设置抽屉截图；额外核对 360px 的更新提示与底栏无重叠。
- 未选中复选框和关闭态开关使用独立控制边界色，避免弱化卡片边界时降低控件辨识度。

首轮 58 项通过，预览隔离测试的自动跳转先于正文可见性采样，导致测试超时；Trace 确认浏览器已经阻断跳转。测试改为就绪后触发脚本导航，并必须观察到真实 CSP 阻断事件，保留零外连和本地服务零请求断言。CSS 动画暂停采样也等待暂停提交完成。预览文件 4 项连续 6 轮共 24 次通过，再次冻结代码并重启开发服务器后完成最终全套验证。生产预览隔离实现未修改。
