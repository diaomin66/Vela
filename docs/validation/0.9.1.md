# AhaX 0.9.1 验收记录

本版继续使用 [0.9.0 本地完整验收](0.9.0.md) 的自定义存储与线程删除实现，修正 Windows 8.3 临时路径暴露的测试来源构造问题。0.9.0 被发布流水线拦截，未公开安装包；未跳过失败测试或放宽原有结果断言。

## 短路径回归

使用 Windows `GetShortPathNameW` 在本机生成真实 8.3 临时目录，在修复前精确复现 CI 的两个失败。历史来源数据库读取已成功，但测试比较长名和短名字符串；改为比较规范化后的文件系统路径。存储测试 fixture 原先根据尚未规范化的短路径创建来源 ID，与正式扫描产生的 ID 不同；现在先规范化已创建的来源目录再构造 fixture，与生产扫描保持一致。

两份恢复文件的期望数量仍为 2，没有修改为允许重复；测试检查原始字节、删除标记和官方刷新警示的断言继续保留。

另将测试中拼接 Windows verbatim 路径的字符串改为 `Path::join`，避免扩展长度前缀下混用 `/` 分隔符。修正仅涉及三个测试文件，生产逻辑未更改。

在真实 8.3 TEMP 下最终完整运行 `--lib --include-ignored --test-threads=1`：**256 项通过，0 失败，0 忽略，耗时 68.47 秒**。两项官方 0.160.0 隔离互操作也在本轮执行通过。没有运行模型请求或操作真实用户线程。
