## 自定义评测超时

新计划默认 300 秒，缺失新字段的旧计划和历史按原 120 秒解释。前后端拒绝 30 秒以下、3600 秒以上及非整数；主体和评审分别获得完整请求时限。超时覆盖响应头及响应体，不重复收费请求；取消不必等待设置的时限。

浏览器新增回归覆盖预设、自定义、错误提示、125 秒计划保存和重开、600 秒临时运行不覆盖定时计划、导出快照，以及 390px 窗口布局和无障碍检查。此前版本的完整浏览器与官方模型协议验收见 [0.5.0 记录](0.5.0.md)。本次没有将此前测试算作重新运行。

原生评测脚本使用真实 Tauri IPC，验证旧字段迁移、125 秒持久化、范围校验、1800 秒设置下立即取消，以及实际等待 30 秒的请求截止时间。该请求报错而不记零分，结果记录真实等待时间，模拟服务收到断连，调用次数不增加。手动与后台定时、历史、报告导出、SVG 解码和重启不重放一并验证。

## 模型路由修复

独立回归覆盖目录精确归属、自定义目录保留、未选中 profile 保留、当前 profile 优先级和同步，以及已知路由与实际服务商不匹配的诊断。

原生验收在隔离配置中将当前 profile 切到第二渠道路由，同时保留错误的直连服务商。诊断报告 `gateway-routing-mismatch`；修复后根配置和当前 profile 均恢复 Vela 服务商及正确目录，继续选择第二渠道，避免被保存的第一渠道默认值覆盖。直连操作移除自有目录引用但保留目录文件。诊断、预览和修复过程不发送上游请求。既有双渠道 JSON/SSE、凭据、托盘后台运行、窗口唤回和原始配置恢复仍通过。

修复对象是配置文件。已运行会话绑定的服务商不会因此被迁移；应用统一目录后需彻底退出、重新打开客户端并新建会话。

## 历史索引恢复

首次原生评测验收出现一次结果文件已完成、历史索引未完成更新的情况；当次测试未收集运行时具体文件错误，不能确定其 Win32 原因。新增错误捕获后，相同安装包完整复跑通过。没有根据该现象扩大文件重试或重发模型请求。

检查发现已有恢复路径会将这种已落盘的终态错误覆盖成“中断”。本版仅对仍在运行的记录标记中断；已完成、已取消、已中断记录恢复时保留结果、时间和错误，仅补齐历史索引。测试覆盖三种终态及重复恢复的幂等性。原生验收脚本同时改为及时报告存储错误，避免只呈现轮询超时。
