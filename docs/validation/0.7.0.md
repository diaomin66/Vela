# AhaX 0.7.0 验收记录

本轮验收使用隔离的 `CODEX_HOME` / `VELA_DATA_DIR`、本机模拟服务和合成 Windows 凭据。不修改真实配置、已安装应用或桌面快捷方式。更新测试只下载和验签，不执行安装。

## 界面与业务检查

- Rust 全库测试：165 项通过。
- 前端单元测试：40 项通过。
- 浏览器回归：36 项通过，包含 17 项通用页面、11 项评测、4 项主题与 4 项预览隔离检查。类型检查和生产构建通过。
- 主题覆盖浅色、深色、跟随系统、跨重载持久化、React 执行前的首屏主题、390px 布局与 Axe 检查。实际安装包中另行验证主题切换和重载保持。
- 单次与定时页面使用不同计划编辑入口，记录按来源隔离；单次糖果和判题使用回答列表，定时保持 48 格时间线。动画自动播放，用户界面的暂停按钮已移除，详情仍支持重新播放。
- 删除以整轮为单位，覆盖单条、勾选、全选、取消确认、运行中禁止删除、未知或无效批次拒绝，以及作品、回答、时间线和历史同步移除。已导出的 JSON 不删除，定时计划不受影响。

## 原生执行和持久化

签名安装包提取后，通过实际 Tauri IPC 与 WebView2 验证计划保存、三种题目、模型文字复评、动画变化、完整原文和提示词、紧凑活动索引、导出路径与磁盘内容。最终本地签名包通过 16 组原生评测检查，发送 9 次本机模拟请求，包含实际等待 30 秒的截止时间验证；超时及取消不自动重发请求。定时计划在后台运行，重启不会重放已经认领的轮次。

删除检查验证运行中混合批次不改变任何记录、无效批次不部分删除、报告与作品文件同步移除、导出字节保持一致、重启后已删记录不会出现在磁盘、索引或界面中。后端测试还覆盖 Windows 阻止索引提交时的报告回滚，以及提交前后暂存文件的启动恢复。

最终回归中捕获到一次 Win32 `1175`，评测在保存第二个结果时按失败路径中断，已生成的回答仍保留。Microsoft 的 `ReplaceFileW` 文档明确该错误下原文件和替换文件保留原名称；修复将其纳入原有最多 250 ms 的本地文件替换重试，继续复用同一个暂存文件。权限错误以及可能部分提交的 `1176` / `1177` 不重试。本地写盘重试不重做业务操作，也不重发模型请求。

新增的重复启动回归还复现了旧初始化顺序的问题：已有评测运行时再次启动应用，第二个进程会在单实例检查前恢复报告，将运行状态写成中断。评测恢复现移至单实例插件确认后的应用初始化；修复后的原生回归确认，前台唤回及后台启动均保持运行中的索引、报告与模型请求数不变。

## 诊断与基础能力

配置、路由与恢复回归覆盖模型发现、原始余额单位、根地址和 `/v1`、双渠道模型路由、原生推理档位、凭据助手、JSON/SSE、来源和令牌拒绝、续传隔离、关闭到托盘、单实例唤回、冲突检查及精确恢复。

新增诊断检查配置字段和表结构、只读属性、受管模型目录实际内容、启用模型、凭据助手和恢复点。原生 UI 验收故意损坏隔离目录内的模型文件，执行「检查 → 预览修复 → 确认修复」，自动重新检查后文件恢复、配置字节保持不变，全程无模型请求。脱敏与备份 DPAPI 预检另有隔离单元测试。参考出处和边界见 [诊断说明](../DIAGNOSTICS.md)。

实际 WebView2 预览验证 CSS、SMIL 和 JavaScript 动画执行、离屏控制和文档释放。父页面、凭据、原生功能、外部网络与其他本机端口仍隔离；主动 IPC 探针没有创建额外预览或返回应用数据。作品的暂停桥仅保留为内部资源管理机制，不再提供用户暂停按钮。

## 安装更名与更新验证

窗口、托盘和安装包改为 AhaX。更新仓库、签名公钥、`app.vela.desktop`、`vela.exe`、数据目录、凭据命名空间及模型 provider / 路由标识保持兼容。

NSIS 迁移通过 31 项隔离检查及实际 Tauri 完整模板编译。覆盖旧注册信息一致性、默认路径复用、显式 `/D` 路径保留、用户重新选择路径、只清理匹配注册项，以及快捷方式目标和参数保留。新旧快捷方式目标冲突时保留原文件。测试只使用 `HKCU\Software\AhaXSmoke\<UUID>` 与临时目录，结束后清理测试键；没有运行真实安装器。

实际更新插件验证正确安装包签名，并拒绝篡改包及版本错配清单。发布工作流在生成签名包之后、公开发布之前执行隔离安装迁移检查。

## 验证边界

本机模拟服务不能代替真实第三方模型质量、计费与协议兼容验收。未在干净 Windows 虚拟机执行首次安装或真实旧版覆盖升级。更新包具有 Minisign 签名和版本绑定，当前没有 Windows Authenticode 代码签名。已移除用户界面的动画暂停操作，预览引擎原有播放控制测试仍用于验证内部生命周期与隔离。
