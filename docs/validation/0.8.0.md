## 能力边界

保护在应用运行期间按配置间隔执行；应用彻底退出、设备离线或第一次成功保护之前没有新快照。本机副本不能单独防护整盘丢失，DPAPI 通常只能由原 Windows 用户解密。首次保护前永久删除且没有其它副本的正文无法仅凭索引还原。

未知格式保留字节并提示，历史依赖验证失败时不显示完整恢复。官方列表仍可能受客户端筛选和当前来源影响；AhaX 不直接写官方数据库表。

发布包包含更新器签名，当前没有 Windows Authenticode 代码签名。本轮没有在干净虚拟机执行首次安装或旧版覆盖安装。
