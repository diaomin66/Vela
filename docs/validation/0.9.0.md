# AhaX 0.9.0 本地验收与发布拦截记录

本版新增自定义数据位置、可撤销线程删除和回收站。测试使用隔离的应用身份目录、官方数据目录与合成线程；没有修改真实用户配置、原始线程或已安装软件，没有运行真实安装器或更新安装。

## 路径与迁移

位置模块的 17 项定向测试通过，覆盖环境变量优先级、官方相对 SQLite 路径、坏配置可诊断、目录重叠和联接拒绝、来源离线、复制冲突、SQLite WAL 一致性、失败重试、替换或取消待重启方案、Windows 长路径，以及从独立位置返回默认布局。

额外扫描回归验证每个历史来源记住自己的 SQLite 路径；切换当前 home 后不会改指另一个数据库，从加密来源清单重建后映射仍然保留。无法解析的旧来源配置不阻止原始日志保护，但会阻止无法确认范围的官方写操作。

官方目录只切换访问位置。AhaX 大数据迁移保留原目录，目标文件存在不同内容时拒绝覆盖；不会把恢复默认位置解释为合并两份历史。

实际桌面验收发现过长路径发布故障：源 manifest 路径长 349 字符，目标长 371 字符，Rust 文件读写成功，但 Win32 不覆盖发布缺少 extended-length 路径。故障时原位置继续生效，双方文件保留。新增真实目录结构回归在修复前复现同一错误，修复后通过，不依赖缩短路径或修改系统长路径策略。

## 线程删除与撤销

Rust 全量 `--lib --include-ignored` 在本机 GNU 工具链下 253 项通过、0 失败、0 忽略。随后增加两项删除回归：更高版本 `state_N.sqlite` 阻止沿用旧关联图，以及来源目录或数据库映射变化使删除预览失效。最终删除模块定向 14 项全部通过，包含新增项及受影响的真实互操作；计入长路径迁移回归，当前测试集合共有 256 项。

两个需要明确指定程序路径的官方互操作测试均使用本机选定的 0.160.0 可执行文件。验证包括缺失历史恢复后的活动与归档读取，以及同一逻辑线程的两份活动/归档 rollout：保护 → 官方删除 → 源文件和官方列表均移除 → AhaX 清单重建不复活 → 回收站撤销 → 两份文件原字节恢复 → 官方 `thread/read` 读取原消息。

异常回归覆盖正在写入的记录、分页格式阻断、派生子线程和历史引用、过期预览、目标冲突、损坏回收站、RPC 或落盘中断，以及旧 SQLite 清单不能绕过独立删除标记。部分恢复保留未完成状态；文件已恢复而官方索引刷新失败时返回明确警示。

## 前端

前端全量单测 51 项和 Playwright 53 项通过。发布前修复中断删除状态及恢复成功后的索引警示，修复后 TypeScript 检查、相关单测 13 项和线程 Playwright 8 项通过。新增回归覆盖「中断删除 → 回收站检查 → 撤销成功但官方列表待刷新」完整流程。

设置独立提供常规、数据位置两个子页。验证路径草稿保留、预览失效、失败重试、待重启撤回、两类保存入口隔离，以及批量删除保留未执行项。浅色/深色、900 × 680 与 390 × 844 的布局和 Axe 检查通过；原生文件夹选择器本身未进行自动点击。

## 本地桌面包

签名 NSIS 构建成功。使用构建后的真实 `vela.exe` 完成 9 组原生检查：新用户空清单、活动/归档与半行记录、缺失线程精确恢复、预览后的并发目标保护、设置与清单跨重启持久化、独立加密清单重建、不完整线程及过期删除预览阻断、五个 AhaX 自定义目录在重启时统一迁移，以及坏官方 SQLite 配置不阻止桌面启动。迁移后的保护副本仍可精确找回，目标冲突文件未被覆盖。报告和截图位于 `artifacts/threads-native-fDfhXo/`。

安装器迁移检查 31 项全部通过，仅使用隔离注册表与合成快捷方式。实际更新插件对本地签名安装包下载验签通过，对被篡改文件及公告版本与签名不一致的场景均拒绝；明确 `installed=false`。记录分别位于 `artifacts/installer-branding-1b87ee2b160248ad9d74e48640a8cad7/` 与 `artifacts/updater-smoke-k4FQrL/report.json`。

## 发布拦截

GitHub Release run `37189137124` 对应提交 `e93d28c`。Windows MSVC 编译及前端 53 项测试通过；Rust 252 项通过、2 项失败、2 项显式互操作按设计忽略，测试耗时 63.32 秒。签名构建、发布和安装迁移步骤均未执行，0.9.0 没有公开 Release 或更新安装包。

两项失败均由 CI 使用 Windows 8.3 临时路径暴露：历史来源的 SQLite 路径断言比较了长名与短名字符串；部分删除恢复的合成 fixture 在目录规范化前创建来源 ID，导致再次扫描把两份文件误计为四份。修正版使用 0.9.1，保留 0.9.0 标签用于追溯，不移动已有标签。

## 验证边界

可逆删除当前支持经过验证的传统会话格式。分页历史不开放删除，原因是只读索引刷新尚不足以重建其历史投影；不通过隐式运行模型任务来尝试恢复。撤销范围为原始会话记录，独立附件、目标等官方元数据不承诺完整还原。

本机保护与跨设备灾备、Windows 用户加密材料、首次保护前已永久丢失内容等边界见 [线程使用说明](../THREADS.md)。
