## 前端和视觉

- TypeScript 与生产前端构建通过；Vitest 7 个文件、53 项通过。
- 冻结代码并重启开发服务器后，完整 Playwright **57 项通过，0 失败**，耗时约 1.3 分钟。覆盖渠道、推理、评测、线程找回与删除、回收站、路径、更新、主题及预览隔离。
