# 界面设计规范

AhaX 是面向中文用户的桌面工作台。界面首先帮助用户读懂当前状态、定位记录并执行操作。六个工作区遵循同一套规范。

## 信息层次

- 页面标题与主要操作放在同一行；任务子导航位于页面标题上方。
- 概览只保留影响操作的状态、数量与范围，避免挤占列表首屏。
- 筛选紧邻结果，列名与每行字段对齐。长内容可以换行或省略，但完整值应能在详情或悬停提示中读取。
- 主要名称和数值使用正文色；时间、路径、单位与说明使用辅助色。状态同时包含文字，不能仅凭颜色识别。
- 同类操作使用相同按钮样式；保存、检查和开始检测等主要动作使用强调色，常规动作使用中性按钮。

## 基础尺寸

| 用途 | 规范 |
| --- | --- |
| 页面标题 | 26px，窄屏 22px |
| 主要信息、输入文字 | 14px |
| 操作和次要正文 | 13px |
| 时间、标签、补充信息 | 最低 12px |
| 常规按钮 | 最低 38px 高 |
| 小型控件圆角 | 10–12px |
| 内容与卡片圆角 | 18–24px |
| 弹窗、抽屉圆角 | 24px |

小屏适配通过换行、列布局变化与滚动完成，不再缩小字号。浅色与深色共享布局、间距与含义；主题差异由 `src/tokens.css` 提供。

## 视觉语言

窗口背景与导航采用同一底色，正文置于独立圆角工作区。浅色为中性白，深色为石墨黑；主操作为黑白反转，小范围暖色用于品牌与导航选中状态。成功、警告、错误保持文字与语义色同时表达。

搜索和输入使用填充式表面；渠道与作品作为独立对象保留轻边界，连续记录依靠留白与短直分隔组织。避免每个状态、每一行都再套一层卡片。模型列表只使用一套列标题，渠道分组不重复列名。抽屉保留固定头尾与独立滚动，外观偏好可从顶栏和设置同步切换。

## 样式边界

- `src/styles.css`：排版与共享控件。
- `src/shell.css`：标题栏、导航、工作区滚动与底栏。
- `src/workspaces.css`：渠道、模型库与配置恢复。
- `src/pages/*`、`src/components/*` 的 CSS：对应模块的专用布局。

页面不能覆盖全局导航或标题栏。优先复用共享按钮与输入，避免同等选择器优先级因导入顺序而改变外观。业务流程继续复用现有组件、Radix、TanStack Query 和后端服务，不另建状态或弹窗框架。

## 验收方式

检查 1180×820、900×680 的桌面窗口及 390px 窄屏，覆盖两种主题和有数据的页面。除视觉检查外，运行可访问性、键盘操作、长路径、批量操作、主题首屏和信息可读性测试。正文滚动后主导航与底栏必须仍然可达。
